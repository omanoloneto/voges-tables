Voges Tables: a simple spreadsheet for macOS, Windows and Linux. Part of the Voges suite, next to Voges Word and Voges Pencil.

## What's new in Voges Tables 1.0.1

- Voges Updater now also offers the Voges apps you don't have yet, below the updates. They are never ticked for you: pick the ones you want, or follow the link to the app's page first.
- Apps that join the suite from now on show up there without a new version of Voges Tables. The updater reads them from a list on the Voges website, signed with the same key as the releases.

## Install

Page with the downloads and step-by-step instructions: https://omanoloneto.pro/voges/tables/

- **macOS** (10.15 or newer, Apple Silicon and Intel): open `VogesTables-macos.dmg` and drag Voges Tables to Applications. The first time, macOS blocks the app because it is not notarized by Apple: go to System Settings → Privacy & Security → Open Anyway.
- **Windows** (10 or 11, 64-bit): run `VogesTables-windows-setup.exe`; it does not need administrator rights. If SmartScreen warns you, click "More info" and then "Run anyway".
- **Linux** (Ubuntu 22.04, Debian 12 or newer and derivatives, 64-bit): `sudo apt install ./voges-tables-linux-amd64.deb`

`SHA256SUMS.txt` lists the SHA-256 of each file, so you can verify the download, and `SHA256SUMS.txt.sig` is its signature.
